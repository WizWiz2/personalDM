# Длительная живая игра в облаке

## Исправления 2026-10-03

На CPU один запрос Qwen занимает несколько минут, а лимит локальной очереди был
120 секунд. Следующий пользовательский ход мог закончиться ошибкой, пока модель
продолжала обрабатывать память предыдущего хода.

- Ожидание интерактивного запроса учитывает конфигурируемый бюджет активного
  транспорта и control-модели, а также отдельный лимит очереди.
- Фоновая память ждёт освобождения слота без ложного таймаута, в том числе если
  интерактивная резервация началась после постановки памяти в очередь. Активный
  запрос ограничен собственным бюджетом и остаётся отменяемым.
- HTTP-бюджет вынесен в `PDM_LLM_HTTP_TIMEOUT_SECONDS`; подмена `httpx` больше
  не нужна. Для этого CPU-стенда установлены control/HTTP 1800 секунд и очередь
  7200 секунд. Это устраняет преждевременный отказ; вычисления не ускоряются.
- Нативная схема проверки владельца действия требует `evidence_quote` из
  исходного пользовательского ввода. Сгенерированная цитата отклоняется до
  замораживания намерения. Грамматическая проверка получает исходный фрагмент.
  Это проверка происхождения свидетельства, а не доказательство понимания смысла.
- Инструкция извлечения намерения отделяет условные будущие действия игрока
  от вопросов к NPC. Литературное качество и выполнение этой инструкции требуют
  отдельной проверки с реальными моделями.

Проверки очереди, публичного жизненного цикла, намерения, схем и модельного
транспорта используют управляемые подмены внешних ответов. Они не считаются
длительной игрой с LLM.

## Способ живой проверки

Действия игрока выбирает сам ассистент после чтения опубликованного ответа мастера.
Ввод отправляется отдельными запросами обычного игрового API; автоматического
игрока и скрипта выбора следующих действий нет. Для текущей кампании игровые
роли работают через вход в ChatGPT, модель `gpt-5.6-luna`.

Автопилот был запущен без согласования, затем остановлен по требованию
пользователя. Его скрипт и обслуживающие его тесты удалены. Сохранённые результаты
автоматических прогонов являются историческими данными и не заменяют личной
оценки кампании. Подробности последних правок — в `tempo-and-turn-budget-repairs.md`.

файлы и инструкции старта позволяют возобновить работу. Сохранение конфигурации
не является запуском процесса или публикацией снимка среды.
