# Исправление ошибок управления ходом — 26 сентября 2026

Конфигурация проверки: рассказчик `huihui_ai/gemma-4-abliterated:e4b`, управление `qwen2.5:7b`, оба окна 4096. Лимит управляющего запроса остался 180 секунд.

## Найденные причины

- Просьбы представиться или объяснить что-либо иногда превращались в исполняемые `service`/`interaction`. Затем оркестратор блокировал это искусственное действие без установленного основания.
- Проверка блокировки требовала, чтобы модель дословно переписала текст контекста. Native JSON Schema не могла гарантировать эту смысловую зависимость.
- Большие инструкции, текст схемы и контекст рассказчика вместе создавали давление на окно управления. В источники обоснования попадали стиль мастера и временные описания.
- Любая повторная попытка автоматически увеличивала бюджет ответа, даже если предыдущий JSON был полным и ошибка относилась к смыслу. Повторение большого отвергнутого ответа дополнительно раздувало запрос.
- При таймауте исходный прогон сохранял этап и сообщение ошибки, но не метрики попыток. Точную долю генерации, повторов и ожидания сервера в тех двух запросах восстановить нельзя.

## Изменения

- До замораживания действий семантическая проверка маркирует каждый кандидат как физическое действие или речь. Грамматика императива определяет адресата, но сама по себе не превращает вопрос в физический акт. Противоречивый общий признак «только информация» не может удалить маркированные физические действия.
- Контекст получает локальные ссылки `E0`, `E1`, …; блокировка выбирает существующую ссылку. Точный источник подставляет движок. Неподтверждённые блокировки по-прежнему отклоняются; прежние точные цитаты поддерживаются.
- Убраны инструкции о стиле, временные описания и повторяющиеся инструкции исполнения из контекста разрешения. Соглашения кампании, карточки, факты и ID сохраняются.
- Текст схемы сокращён; полные ограничения передаются native-декодеру. Закрытые объекты и диапазон замороженных индексов ограничиваются на этапе генерации.
- Бюджет повтора растёт при обрезанном JSON. Большой отвергнутый ответ не копируется в повтор, если это вытеснит исходные данные из окна.
- Для адресованного вопроса требуется `direct_response` с непосредственной репликой. Кивок и ожидание следующего хода не заменяют её. Уже присутствующий адресат не может быть заново создан через `npc_introductions`.
- Метрики неудачного запроса сохраняются в `context_snapshot.control_failure`: этап, модель, попытки, длительность, нагрузка на контекст.
- Сквозная проверка обнаружила потерю второй неудачной попытки перехода при извлечении действий. Инструкция уточнена: невозможность успеха не удаляет совершённую попытку.
